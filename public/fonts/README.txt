Place the licensed IRANYekan font files here with these exact names (woff2):

  IRANYekan-Regular.woff2   (400)
  IRANYekan-Medium.woff2    (500)
  IRANYekan-Bold.woff2      (700)

If the files are missing the site falls back to Vazirmatn / Tahoma, so nothing breaks.
(If you use a different file naming, edit the @font-face block in src/app/globals.css.)
